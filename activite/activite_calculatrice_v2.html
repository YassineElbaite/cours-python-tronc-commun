Étape 1 — Fonction addition()

Explication

Une fonction addition reçoit deux nombres (a et b) et retourne leur somme. C'est la plus simple des 4 fonctions !

An addition function receives two numbers (a and b) and returns their sum. It's the simplest of the 4 functions!

دالة الجمع تستقبل عددين (a و b) وتُرجع مجموعهما. إنها أبسط الدوال الأربع!

Complétez le code

Remplacez chaque ___ par le bon mot :

Replace each ___ with the correct word:

استبدل كل ___ بالكلمة الصحيحة:

calculatrice.py — Étape 1 
# Étape 1 : Fonction addition

def _______(a, ___):
    return a _ b

# Test de votre fonction :
resultat = _______(10, 5)
print("10 + 5 =", ________)
💡
Indice : Le nom de la fonction est addition. Le symbole pour additionner est +. La variable du résultat s'appelle resultat.
Hint: The function name is addition. The symbol to add is +. The result variable is called resultat.
تلميح: اسم الدالة هو addition. رمز الجمع هو +. متغير النتيجة يُسمى resultat.
⚠️
N'oubliez pas l'indentation (4 espaces) avant return !
Don't forget the indentation (4 spaces) before return!
لا تنسَ المسافة البادئة (4 مسافات) قبل return!
✅ Résultat attendu
Output
10 + 5 = 15

Étape 4 — Fonction division()

Explication spéciale

La division est spéciale : on ne peut pas diviser par zéro ! Il faut vérifier avec un if avant de diviser.

Division is special: you cannot divide by zero! You need to check with an if before dividing.

القسمة خاصة: لا يمكن القسمة على الصفر! يجب التحقق باستخدام if قبل القسمة.

Complétez le code
calculatrice.py — Étape 4
# Étape 4 : Fonction division (avec vérification !)

def ________(a, b):
    if b __ 0:
        return "Erreur : division par zéro !"
    ____:
        return a _ b

# Tests :
print("15 ÷ 3 =", ________(15, 3))
print("10 ÷ 0 =", ________(10, 0))
💡
Indices : Le symbole "égal à" en Python c'est ==. Le mot après if quand la condition est fausse c'est else. La division c'est /.
Hints: The "equal to" symbol in Python is ==. The word after if when condition is false is else. Division uses /.
تلميحات: رمز "يساوي" في Python هو ==. الكلمة بعد if عندما يكون الشرط خاطئاً هي else. القسمة تستخدم /.
✅ Résultat attendu
Output
15 ÷ 3 = 5.0
10 ÷ 0 = Erreur : division par zéro !

Explication

Le menu regroupe toutes vos fonctions. Il demande à l'utilisateur quelle opération il veut faire, puis appelle la bonne fonction. C'est la partie où tout le groupe travaille ensemble !

The menu brings together all your functions. It asks the user which operation they want, then calls the right function. This is where the whole group works together!

القائمة تجمع كل الدوال. تسأل المستخدم أي عملية يريد، ثم تستدعي الدالة الصحيحة. هذا هو الجزء الذي يعمل فيه الفريق بأكمله معاً!
